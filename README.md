# Mr_Kinako | Personal Page (card)

Моя персональная страница (SPA), выполненная в эстетике небольшого минимализма, с цветовыми акцентами фиолетовых оттенков. Здесь есть информация о железе и ссылки на некоторые медиа-ресурсы, в том числе мои. 

Также здесь хранятся правила пока одного проекта discord сервера, немного местами в стиле Linux (нравится такой вайб, особенно в сочетании цветовых акцентов страницы).

## 🛡️ Безопасность и Ответственность

Для меня важна честность и надежность, поэтому исходный код этого проекта полностью открыт:

* **Прозрачность:** Вы можете лично убедиться, что сайт не собирает личные данные, не использует LocalStorage для слежки и не содержит вредоносных скриптов.

* **Static Only:** Проект не имеет бэкенда или базы данных. Нету серверных функций в классическом восприятии, есть только некоторые инструкции для отдачи каких-то файлов на сайте (роутинг). Статика, работающая на Vercel.

* **XSS Mitigation:** Использование React для рендеринга данных и параметров путей обеспечивает автоматическое экранирование контента, предотвращая большинство типов межсайтового скриптинга (XSS).

## 🔧 О разработке

**Stack:** Vite + React 19 + Type Script + SCSS Modules.

Я работаю над этим проектом, активно используя возможности **AI (Gemini (free tier))**. 

* **Философия:** Для меня это способ воплотить идеи, минуя барьер отсутствия фундаментального CS-образования. Я использую AI для большинства кода и рутины, однако стараюсь оставлять за собой право править код. Также стараюсь оставлять за собой право всегда принимать архитектурные решения, или заниматься другим творчеством в процессе.

* **Авторство:** Код может содержать сгенерированные фрагменты, но логика роутинга, структура компонентов и дизайн-система — результат моих осознанных решений.

* **Прозрачность:** Тексты (включая этот) могут быть созданы или оптимизированы нейросетью. Я редактирую их вручную, но сохраняю долю их участия ради скорости и возможно чуть более лучшего качества текста. В большинстве своём на комментарии в коде не стоит полагаться как на истину - они могут отставать от темпов разработки.

* **Честность:** У меня нет жёсткого плана работы с ИИ, я действую интуитивно и открыто признаю это перед пользователями.

* **Версионирование:** Я, честно говоря, понятия не имею, как правильно именовать версии (v1.0, v1.1 и т.д.) по канонам. Помню, что существует автоматизация этого процесса (например, для Discord-ботов), но пока не внедрял её здесь. Цифры в заголовке — вещь скорее символическая и отражает моё внутреннее ощущение прогресса проекта.
